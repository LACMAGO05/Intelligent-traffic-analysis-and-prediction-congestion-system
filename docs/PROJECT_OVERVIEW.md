# TrafficPro

AI-powered hybrid traffic prediction system for Buea.

Goal:
Combine:

1. Google Maps predictions
2. LightGBM model predictions
3. Local contextual intelligence

to generate more accurate traffic predictions.

Main Users:
- Commuters
- Drivers
- Students
- Businesses

Core Features:
- Route prediction
- Traffic pressure score
- AI chatbot
- Chat history
- Weather intelligence
- School intelligence
- Event intelligence
- Holiday intelligence

Tech Stack:
- Django
- PostgreSQL
- JavaScript
- Tailwind
- LightGBM
- Google Maps API
- Supabase
